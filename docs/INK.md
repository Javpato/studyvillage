# Ink, notebooks and shared pages

Open **Ink notebook** from the phone or a notebook desk. Private notebooks are independent of furniture and village sessions. Pen, highlighter, whole-stroke and partial erasure, lasso/move/copy/paste/delete, text, lines, rectangles, undo/redo, page duplication/reordering and recoverable page deletion are implemented. A finger pans by default; two fingers zoom. Enable finger drawing explicitly when desired. Fit page and Rotate page affect the viewport; stored geometry stays in document coordinates.

The writing surface opens with a compact tool picker, ink colour and undo/redo. The book button opens the notebook/document library, where PDF import is directly available; the materials station opens this library. The options button reveals four labelled tabs: Ink and selection, Page, Files and Share. Page text, paper, zoom and rotation live under Page; clipboard operations under Ink and selection; exports under Files; room sharing and recovery under Share. Page navigation and a new-page button remain beside the save status. Escape closes the open drawer before closing the notebook. This uses [progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/) to keep document management available without crowding the writing surface. Final desktop, phone, library and French views are recorded in `docs/verification/`.

In the notebook, open **Options → Ink and selection → Apple Pencil mode**. This device preference is shared with the room whiteboard’s **More** menu, survives reload and is included in full backups. It starts disabled to preserve the previous input settings. When enabled, Pencil writes while fingers pan/pinch; the finger-drawing checkbox is unavailable until the mode is disabled.

The input module gives the pen priority even if a hand touches the page first: an interrupted finger edit is rolled back, then the pen starts immediately without a pressure threshold. Contacts already present or arriving during a pen stroke remain excluded until lifted, and new contacts have a short 250 ms exclusion period after pen-up; explicit Pencil mode also excludes broad contacts (40 CSS pixels). Coalesced samples are retained, with an older-browser fallback, and the final pointer-up point is included. Geometry is read once per input batch. Cancellation, lost capture, hiding the app and orientation changes roll back an interrupted edit. Pressure, tilt, timestamps and subpixel positions are preserved. Constant-pressure inputs have a usable fallback. Live ink draws onto a separate canvas without redrawing all prior objects for every sample. Backing resolution adapts to zoom/device pixel ratio, capped at twice document size to bound tablet memory. Pressure widths are grouped in eighth-pixel bands for rendering; original pressure data is unchanged.

**Shared board** opens a separate copy for the current room, or the village when outside a room. **Share a copy of this page** sends only the selected page. Ordinary ink remains editable. A PDF page is flattened into a PNG containing its visible page and annotations; no original PDF bytes, attachment ID or other page is shared. The original private notebook never receives future shared edits. **Save personal copy** creates a new private notebook from the selected shared page.

Each participant edits their own shared ink and text layer. A room owner can explicitly enable moderation of other authors' strokes. Operations use stable object IDs, expected revisions and unique operation IDs. Independent layers merge; stale edits are rejected instead of overwriting later work. Undo touches only the objects changed by that local action and refuses if another device has subsequently changed them. Partial erasure produces new immutable stroke fragments while keeping the original as an undoable tombstone.

The temporary host and persistent server use the same `InkAuthority`. Room access is checked before requests and before each outgoing chunk; the server persists state in its SQLite transaction before acknowledgement. Temporary hosts persist acknowledged shared state in IndexedDB. Incoming documents and operations are schema validated. Payloads are chunked into bounded messages; assembly expires after two minutes and has per-sender/global memory bounds. The authority queue is bounded and reports busy instead of accepting unlimited work.

Client operations are durably placed in the IndexedDB outbox before transmission. A lost acknowledgement retries the same operation ID. The outbox is bound to its original session and room; it cannot silently enter a different village. The UI distinguishes local pending work from a host acknowledgement. Conflicts retain recoverable drafts. Export pending operations preserves the transport recovery data; **Save draft and discard pending sends** first saves an editable private notebook, then clears the current room's pending sends. Private editable notebook export remains available independently.

Known boundaries: the shared editor currently has one text layer per author, not freely positioned rich-text objects. Shared page metadata/order/deletion are not edited after creation; save a personal copy to organize it. Existing legacy whiteboards remain alongside this new shared editor. Long shared transfers run while the foreground app is active and resume via the outbox after reconnect; background mobile execution is not guaranteed. Physical Pencil latency, pressure and palm rejection still require actual device validation. PDF.js is lazy-loaded so a PDF incompatibility does not prevent basic village/notebook use; see SETUP.md for browser support.

Automated evidence: `app/tests/pencil-input.test.ts`, `app/tests/e2e/pencil-mode.spec.ts`, `app/tests/documents.test.ts`, `ink-collaboration.test.ts`, `ink-recovery.test.ts`, and `app/tests/e2e/shared-notebook.spec.ts`. The two-person browser journey uses the actual authenticated WebSocket server and verifies selected-page privacy, independent drawing, author-specific undo (including retry after a simulated outbox quota error), saving a private copy, and editing/reloading a recovered draft. A separate browser journey verifies pointer cancellation rolls back an interrupted erasure and that lasso copies, rotation and undo preserve editable geometry. `docs/verification/ink-profile.json` records a measured Linux synthetic fixture (2,001 objects, 52,000 samples, including one 12,000-sample stroke); it is not an older-iPad performance claim. Reproduce using `npm run dev` and `node scripts/profile-ink.mjs`.

The Pencil regression suite exercises deterministic pen/palm event ordering, immediate light marks, coalesced/final samples, pan/pinch, cancelled erasure, undo, reload, and cross-tab mode synchronization in Chromium and Linux WebKit. Its synthetic pointers stub capture because they are not browser-owned hardware contacts. This verifies application behavior; the updated handling still needs a physical iPadOS 17.7.10/Pencil retest after the reported palm interference.
