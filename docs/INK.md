# Ink, notebooks and shared pages

Open **Ink notebook** from the phone or a notebook desk. Private notebooks are independent of furniture and village sessions. Pen, highlighter, whole-stroke and partial erasure, lasso/move/copy/paste/delete, text, lines, rectangles, undo/redo, page duplication/reordering and recoverable page deletion are implemented. A finger pans by default; two fingers zoom. Enable finger drawing explicitly when desired. Fit page and Rotate page affect the viewport; stored geometry stays in document coordinates.

The writing surface opens with a compact tool picker, ink colour and undo/redo. The book button opens the notebook/document library, where PDF import is directly available; the materials station opens this library. The options button reveals four labelled tabs: Ink and selection, Page, Files and Share. Page text, paper, zoom and rotation live under Page; clipboard operations under Ink and selection; exports under Files; room sharing and recovery under Share. Page navigation and a new-page button remain beside the save status. Escape closes the open drawer before closing the notebook. This uses [progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/) to keep document management available without crowding the writing surface. Final desktop, phone, library and French views are recorded in `docs/verification/`.

In the notebook, open **Options → Ink and selection → Pen mode**. This device preference is shared with the room whiteboard’s **More** menu, survives reload and is included in full backups. It starts disabled on a fresh device, then activates automatically on the first pen contact of a session, like Excalidraw. A subsequent manual opt-out is respected for the remainder of that session. When enabled, fingers cannot create ink, shapes or canvas text, or use the eraser; pen and mouse editing remain available. Fingers still pan with one contact and pinch with two, including while a writing or erasing tool is selected. Selection/lasso and moving existing content also remain available to fingers. **Hand** uses the same navigation without switching Pen mode off; changing tools never rewrites the saved preference. Mouse and pen can drag in Hand without editing ink. The finger-drawing checkbox is unavailable until Pen mode is disabled; a previously enabled checkbox cannot bypass this restriction.

Hand navigation requires fresh contacts after switching tools. Switching cancels an unfinished edit, and contacts already resting on the surface stay excluded until lifted. A third contact stops navigation until all contacts lift; lifting one of two fingers returns to one-finger pan. Navigation accepts fresh fingers immediately after pen-up, including broad contacts. Contacts during an active pen stay excluded until lifted, so a resting palm cannot take over a stroke. Selection retains the normal 250 ms post-pen delay. Pinches keep the content under the moving midpoint, accounting for notebook padding, centering and rotated pages; at scroll boundaries, the page remains within its scrollable bounds. Zoom is limited to 20–400% on the board and 25–400% in the notebook, and reversing a pinch responds immediately at those limits.

The implementation was compared with [Excalidraw App.tsx at commit 701b901a0f1ba3d0b390d9cdf63d112e25abac4b](https://github.com/excalidraw/excalidraw/blob/701b901a0f1ba3d0b390d9cdf63d112e25abac4b/packages/excalidraw/components/App.tsx). This is an adaptation of its input behavior, not its full React editor or freehand rendering engine. Pen mode now restricts touch-created ink and erasure instead of restricting all single-finger interaction; browser-native long-press text selection remains suppressed on drawing surfaces.

**Text → Format → Text font → Excalifont (Excalidraw)** selects Excalidraw's current handwriting font on room boards. It is available in the live text field, canvas, clipboard, saved/shared notes and PNG export. The seven upstream font subsets are bundled locally and included in the offline PWA; export waits for the font before measuring text. Existing sans, serif and monospace choices remain available. See ASSETS_LICENSES.md for provenance and licensing.

The input module gives the pen priority even if a hand touches the page first: an interrupted finger edit is rolled back, then the pen starts immediately without a pressure threshold. Contacts already present or arriving during a pen stroke remain excluded until lifted. Selection and normal-mode finger editing have a short 250 ms exclusion period after pen-up; intentional navigation accepts fresh contacts immediately. Broad-contact filtering no longer blocks ordinary finger navigation in Pen mode. Coalesced samples are retained, with an older-browser fallback, and the final pointer-up point is included. Geometry is read once per input batch. Cancellation, lost capture, blur, hiding the app and orientation changes roll back an interrupted edit. A new pen-down recovers an orphaned stroke when the OS omitted its up/cancel event, and window-level completion still works if native capture throws. Notebook pressure, tilt, timestamps and subpixel positions are preserved. Constant-pressure inputs have a usable fallback. Live ink draws onto a separate canvas without redrawing all prior objects for every sample. Backing resolution adapts to zoom/device pixel ratio, capped at twice document size to bound tablet memory. Pressure widths are grouped in eighth-pixel bands for rendering; original pressure data is unchanged.

Native selection/Scribble and application pointer ownership are separate failure paths. The drawing surfaces now cancel non-passive `touchstart`/`touchmove` and Safari gesture events, suppress long-press selection/context menus, and clear a pre-existing DOM selection on entry. The notebook margin follows the same policy as the paper. These listeners are scoped to drawing surfaces, so text fields and intentionally copyable notes retain native selection and browser zoom remains available elsewhere. This prevents known competing browser gestures; it cannot control iPadOS's hardware palm classification.

**Shared board** opens a separate copy for the current room, or the village when outside a room. **Share a copy of this page** sends only the selected page. Ordinary ink remains editable. A PDF page is flattened into a PNG containing its visible page and annotations; no original PDF bytes, attachment ID or other page is shared. The original private notebook never receives future shared edits. **Save personal copy** creates a new private notebook from the selected shared page.

Each participant edits their own shared ink and text layer. A room owner can explicitly enable moderation of other authors' strokes. Operations use stable object IDs, expected revisions and unique operation IDs. Independent layers merge; stale edits are rejected instead of overwriting later work. Undo touches only the objects changed by that local action and refuses if another device has subsequently changed them. Partial erasure produces new immutable stroke fragments while keeping the original as an undoable tombstone.

The temporary host and persistent server use the same `InkAuthority`. Room access is checked before requests and before each outgoing chunk; the server persists state in its SQLite transaction before acknowledgement. Temporary hosts persist acknowledged shared state in IndexedDB. Incoming documents and operations are schema validated. Payloads are chunked into bounded messages; assembly expires after two minutes and has per-sender/global memory bounds. The authority queue is bounded and reports busy instead of accepting unlimited work.

Client operations are durably placed in the IndexedDB outbox before transmission. A lost acknowledgement retries the same operation ID. The outbox is bound to its original session and room; it cannot silently enter a different village. The UI distinguishes local pending work from a host acknowledgement. Conflicts retain recoverable drafts. Export pending operations preserves the transport recovery data; **Save draft and discard pending sends** first saves an editable private notebook, then clears the current room's pending sends. Private editable notebook export remains available independently.

Known boundaries: the shared editor currently has one text layer per author, not freely positioned rich-text objects. Shared page metadata/order/deletion are not edited after creation; save a personal copy to organize it. Existing legacy whiteboards remain alongside this new shared editor. Long shared transfers run while the foreground app is active and resume via the outbox after reconnect; background mobile execution is not guaranteed. Physical Pencil latency, pressure and palm rejection still require actual device validation. PDF.js is lazy-loaded so a PDF incompatibility does not prevent basic village/notebook use; see SETUP.md for browser support.

Automated evidence: `app/tests/pencil-input.test.ts`, `app/tests/e2e/pencil-mode.spec.ts`, `app/tests/documents.test.ts`, `ink-collaboration.test.ts`, `ink-recovery.test.ts`, and `app/tests/e2e/shared-notebook.spec.ts`. The two-person browser journey uses the actual authenticated WebSocket server and verifies selected-page privacy, independent drawing, author-specific undo (including retry after a simulated outbox quota error), saving a private copy, and editing/reloading a recovered draft. A separate browser journey verifies pointer cancellation rolls back an interrupted erasure and that lasso copies, rotation and undo preserve editable geometry. `docs/verification/ink-profile.json` records a measured Linux synthetic fixture (2,001 objects, 52,000 samples, including one 12,000-sample stroke); it is not an older-iPad performance claim. Reproduce using `npm run dev` and `node scripts/profile-ink.mjs`.

The Pencil regression suite exercises deterministic pen/palm event ordering, immediate light marks, coalesced/final samples, pan/pinch, cancelled erasure, undo, reload, and cross-tab mode synchronization in Chromium and Linux WebKit. `app/tests/e2e/hand-navigation.spec.ts` additionally covers both surfaces, blocking finger writing/erasure for every writing tool, one-finger pan, pinch zoom, finger selection/movement, preserved mode preferences, tool transitions, third-contact quarantine, broad navigation contacts, mouse/pen dragging without ink edits, rotated pinch anchoring and notebook zoom limits. Its synthetic pointers stub capture because they are not browser-owned hardware contacts. This verifies application behavior; Hand navigation still needs a physical iPad/Pencil trial. Use the hosted web app for the iPad trial. Open it online to download the update, then close all existing Safari/PWA windows for StudyVillage and reopen it to activate the new offline build. `npm run dev:lan` remains an optional HTTPS preview on the local Wi-Fi; that address has separate browser storage from the public site.
